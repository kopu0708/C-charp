### 배열 분할하기 
Array.Copy()는 배열의 일부를 다른 배열에 복사하는 기능으로 나쁘지 않았지만 다른 방법도 있다.

System.Range라는게 있는데 시작 인덱스와 마지막 인덱스를 이용해서 범위를 나타낸다. 예시를 보자 

```c#
System.Range r1 = 0..3; // 이걸 [] 사이에 인덱스 대신 넣으면 분할된 배열이 반환된다.
int [] sliced = scores[r1]; // 배열이 나온다.

int[] sliced2 = scores[0..3]; // 이렇게 직접 .. 연산자를 넣으면 더 간결하다.
```
이렇게 .. 연산자를 쓴다. 왼쪽은 시작 인덱스, 오른쪽은 마지막 인덱스가 오는데 주의 할 점이 있다. 

시작인덱스는 포함되어 분할 결과에 나오지만 마지막 인덱스는 제외된다. 0..3 이면 0,1,2 인덱스만 나온다는 말이다. 왜요?

반개구간 표기법이란게 있는데 이거랑 같은 설계이기 때문이다. 그냥 마지막 인덱스는 항상 제외된다! 라고 알아두면 문제가 없을 것이다.

### 다차원 배열 
아까 말했듯이 2차원이 있으면 3차원 4차원도 있을 것이다. 이걸 다차원 배열이라한다. 차원이 둘 이상인 배열말이다. 차원이 늘어날수록 요소에 접근 할 때 사용하는 인덱스의 수가 늘어나는 점만이 다를 뿐이다.

사실 3차원 배열까지만 가도 상상하기가 어렵다. 한번 종이에 대고 그려봐라 3차원까지는 그렇다 치지만 4차원부터는 감도 안 잡힌다. 

어디서 본건데 그래서 3중 for문을 넘어가기 시작하면 그거는 잘못된 코드라고 했었다. 

유지보수가 어려워지고 대부분의 경우 데이터 구조 설계를 다시 해야한다는 신호이다. 

그럼 선언을 어떻게 하는지 보고 바로 예제로 넘어가자 3차원 같은 복잡한 구조는 선언을 할때 명시적을 크기를 지정해주는게 좋다. 

그래야 나도 안 헷갈리고 컴파일러가 초기화 코드와 선언문에 있는 배열의 차원 크기를 비교해서 이상이 없는지 검사해줄 수 있다. 

```c#

```

### 가변 배열 
이제까지 우리는 2차원 배열의 요소에 접근할 때 첨자 두 개를 사용해야 했다. 하나만 사용해서 1차원 배열에 접근하거나 하는 것은 불가능 했다.

가장 큰 차이점은 행마다 열 수를 다르게 줄 수 있다는 점이다. 

가변 배열은 이러한 다차원 배열과 달리 배열을 요소로 사용해 접근할 수 있다. 

```c#
데이터_형식[][] 배열_이름 = new 데이터_형식[가변_배열의_용량][];

int[,]  → 다차원 배열. 모든 행의 열 수가 같음
int[][] → 가변 배열. 행마다 열 수가 달라도 됨
```
이런 형식으로 선언을 한다.  이어서 초기화 시키는 법도 보자
```c#
int[][] jagged = new int[3][];
jagged[0] = new int[5] {1,2,3,4,5};
jagged[1] = new int[] {10,20,30};
jagged[2] = new int[] {100,200};
```
이렇게 선언과 동시에 초기화가 가능하다.  이제 예제를 보자 딱히 생각나는게 없어서 클로드 한테 상황을 달라고 했다. [예제06](06_JaggedArray.cs) 

### 컬렉션 
컬렉션이 뭐죠? 같은 성격을 띤 데이터의 모음을 담는 자료구조를 말한다. 

배열도 .Net에서 제공하는 다양한 컬렉션 자료구조의 일부이다. .Net이 제공하는 컬렉션들이 무조건 상속해야 하는 ICollection 인터페이스를 상속하고 있기 때문이다.

배열 말고도 다양한 컬렉션 클래스들이 있는데 그중에 4가지를 보자(ArrayList, Queue, Stack, Hashtable) 

#### ArrayList 
ArrayList는 가장 배열과 닮은 컬렉션이다. 사실 배열의 가장 큰 불편한 점이 뭔가? 그건 바로 크기를 미리 정해둬야한다는 점이다. 

이 컬렉션을 쓰면 미리 용량을 지정할 필요 없이 필요에 따라 자동으로 그 용량을 늘리거나 줄어든다. 

앞서 말했듯이 이것들은 클래스로 정의 되어 있다. 그 말은 즉 메서드들을 달고 있다는 말이다. 가장 중요한 메서드 3가지가 있다.

Add(), RemoveAt(), Insert() 영어를 배웠다면 대충 예상이 갈거다 무슨 기능인지 

```c#
ArrayList list = new ArrayList();
list.Add(10); // Add는 가장 마지막에 있는 요소 뒤에 새요소를 추가한다. 
list.Add(20);
list.Add(30);
list.RemoveAt(1); //20을 삭제
list.Insert(1,25); //25를 1번 인덱스에 삽입한다. 그럼 10 25 30이 저장되어 있겠죠?
```
간단하다. 교제에 나오는 예제를 그대로 보기전에! 사실 이건 좀 낡은 방식이다. 

#### ArrayList 대신 List<> 
제네릭이란게 c#에 도입되고 나서부터 도입된건데 제네릭은 나중에 알아보고 ArrayList말고 왜 List<>를 쓰라고 하냐?

일단 ArrayList는 선언할 때 타입을 지정 하지 않는다. 그래서 뭐든 들어가지만 꺼낼 때마다 명시적으로 형변환을 해줘야한다. 

그렇다 보니 박싱/언박싱이 일어나 속도가 저하되기도 한다. 

그건 알겠는데요 제네릭이 뭐에요? 그건 나중에 일반화 프로그래밍을 할때 이야기해주겠다. 바로 다음 챕터이다. 

```c#
// ArrayList — 꺼낼 때 형변환 필요
int n = (int)list[0];

// List<int> — 그냥 꺼내면 됨
int n = list[0];
```
