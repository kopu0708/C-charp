### System.Array
c#은 모든 것이 객체이다. 배열도 객체이다. 당연히 기반이 되는 형식이 있다. 배열은 System.Array 클래스에 대응된다. 

저기 있는 메소드 프로퍼티들 쓸 수 있다는 말임 

sort(), BinarySearch<T>(), IndexOf(), TrueForAll<T>()...등등 

이렇게 있는데 의문이 하나 있다. <T>() 이런게 뒤에 붙은 친구들은 뭐란 말인가? 

<T>는 형식매개변수라고 하는데, 이들 메소드를 호출할 때는 T 대신 배열의 기반 자료형을 인수로 입력하면 컴파일러가 해당 형식에 맞춰 동작하도록 메소드를 컴파일한다.

### 배열 분할하기 
Array.Copy()는 배열의 일부를 다른 배열에 복사하는 기능으로 나쁘지 않았지만 다른 방법도 있다.

System.Range라는게 있는데 시작 인덱스와 마지막 인덱스를 이용해서 범위를 나타낸다. 예시를 보자 

```c#
System.Range r1 = 0..3; // 이걸 [] 사이에 인덱스 대신 넣으면 분할된 배열이 반환된다.
int [] sliced = scores[r1]; // 배열이 나온다.

int[] sliced2 = scores[0..3]; // 이렇게 직접 .. 연산자를 넣으면 더 간결하다.
```
이렇게 .. 연산자를 쓴다. 왼쪽은 시작 인덱스, 오른쪽은 마지막 인덱스가 오는데 주의 할 점이 있다. 

시작인덱스는 포함되어 분할 결과에 나오지만 마지막 인덱스는 제외된다. 0..3 이면 0,1,2 인덱스만 나온다는 말이다. 왜요?

반개구간 표기법이란게 있는데 이거랑 같은 설계이기 때문이다. 그냥 마지막 인덱스는 항상 제외된다! 라고 알아두면 문제가 없을 것이다.

### 2차원 배열 
내가 한번 문명 같은 육각형 타일을 가진 턴제 타워 디펜스 게임을 만들고 싶은적이 있다. 

그때 내가 이래저래 그리드 맵 만드는 법을 찾아봤었는데 그때 이제 딕셔너리나 헤시 같은 자료형을 알게됬다. 아무튼 저게 중요한게 아니고 2차원 배열은 여러가지로 많이 쓰인다는 것을 말하고 싶었다.

근데 2차원 배열이란게 무슨 소리인가? 우리가 앞서 했던 배열은 1차원 배열이라고 한다. 단순한 한 줄짜리 목록이다. 근데 아래로 하나더 붙이자 그럼 행과 열이 생기겠다.

행과 열을 가진 배열이라고 생각하면 되갰다. 2차원도 있으면 3차원 4차원도 있지 않겠는가? 나중에 이야기 하겠다. 그건 

일단 2차원 배열은 어떻게 선언하는지 부터 보겠다.
```c#
데이터_형식[,] 배열이름 = new 데이터_형식[2차원_길이, 1차원_길이];
```
이런 행태이다. 위 예시와 차이점을 보자 일단 []사이에 ,가 들어간다. 그리고 크기를 2개 받는다. 몇 행 몇 열인지 말이다. 

그럼 초기화 방식도 보자 

```c#
int[,] arr = new int[2,3] {{1,2,3},{4,5,6}}; //배열의 형식과 길이를 명시
int[,] arr2 = new int[,] {{1,2,3}, {4,5,6}}; //배열의 길이를 생략
int[,] arr3 = {{1,2,3},{4,5,6}};// 형식과 길이를 모두 생략 
```
그럼 접근은 어떻게 할까? 간단하다. 몇번째 행의 몇번쨰 열을 보고 싶은지를 입력해주면 된다. 예제로 알아보자
