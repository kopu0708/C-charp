## 스택과 힙

스택은 **정적 메모리 할당**에 사용되며 컴파일 시간에 크기가 정해진다.
함수 호출과 로컬 변수가 저장되며, 함수가 종료되면 메모리가 자동으로 해제된다.

힙은 프로그램 실행 중에 동적으로 메모리 크기가 할당된다.

### 스택의 작동 원리

가장 나중에 들어온 데이터가 가장 먼저 나간다. 이를 **LIFO(Last In First Out)** 라고 한다.

- 속도가 빠르고 접근 방식도 단순하며 메모리 관리가 자동
- 메모리 크기가 제한적 — 초과 시 **스택 오버플로우** 오류 발생

### 힙의 작동 원리

프로그램 실행 중 필요한 만큼 할당하고 해제할 수 있다. 메모리 크기가 유동적이다.

다 사용한 메모리는 명시적으로 해제하는 것이 좋다. 안 하면 메모리 사용량이 누적되어 성능이 저하된다. 이를 **메모리 누수(Memory Leak)** 라고 한다.

> C#은 **가비지 컬렉터(GC)** 가 주기적으로 더 이상 사용하지 않는 데이터를 자동 수거한다.

## 문자열 숫자로, 숫자를 문자열로 바꾸기

C#에서는 `Parse()` 메서드로 문자열을 숫자로 변환할 수 있다.

```csharp
int a = int.Parse("12345");
```

숫자를 문자열로 바꿀 때는 `object`로부터 상속받은 `ToString()`을 사용한다.

```csharp
int c = 12345;
string d = c.ToString();
```

## 상수와 열거

### 상수 (const)

```csharp
const 자료형 상수명 = 값;
```

선언 시 반드시 초기화해야 하며 이후 값을 변경할 수 없다.

> **왜 필요한가?** 변경하면 안 되는 값을 실수로 바꾸는 것을 컴파일러가 막아준다.

### 열거 (enum)

여러 개의 상수를 같은 범주로 묶어 관리할 때 사용한다.

```csharp
enum 열거형식명 : 기반자료형 { 상수1, 상수2, 상수3 }
```

- 기반 자료형은 정수 계열만 가능 (생략 시 `int`)
- 컴파일러가 0부터 순서대로 값을 자동 할당

```csharp
enum DialogResult { Yes, No, Cancel, Confirm, OK }

DialogResult result = DialogResult.Yes;
```

## Nullable 형식

값이 비어있어야 하는 변수가 필요할 때 사용한다.

```csharp
int? a = null;
Console.WriteLine(a.HasValue); // False

a = 37;
Console.WriteLine(a.HasValue); // True
Console.WriteLine(a.Value);    // 37
```

| 속성 | 설명 |
|------|------|
| `HasValue` | 값을 가지고 있으면 `true`, 없으면 `false` |
| `Value` | 변수에 담긴 값 (null이면 예외 발생) |

## var

컴파일러가 자동으로 형식을 추론해주는 키워드. 반드시 선언과 동시에 초기화해야 한다.

```csharp
var a = 3;       // int로 추론
var b = "hello"; // string으로 추론
```

> **지역 변수로만 사용 가능.** 클래스 필드 선언에는 사용 불가.

**`object`와의 차이:**

| | `var` | `object` |
|--|-------|----------|
| 타입 결정 시점 | 컴파일 타임 | 런타임 |
| 타입 변경 | 불가 | 가능 |

## 연산자

### 산술 연산자

| 연산자 | 설명 |
|--------|------|
| `+` | 덧셈 |
| `-` | 뺄셈 |
| `*` | 곱셈 |
| `/` | 나눗셈 (몫) |
| `%` | 나눗셈 (나머지) |

### 증가 연산자와 감소 연산자

```csharp
int a = 10;
Console.WriteLine(a++); // 10 출력 후 11로 증가
Console.WriteLine(++a); // 12 출력
```

- **전위** (`++a`) : 증가 후 반환
- **후위** (`a++`) : 반환 후 증가

### 관계 연산자

`<` `>` `<=` `>=` `==` `!=`

### 논리 연산자

| 연산자 | 의미 |
|--------|------|
| `&&` | AND |
| `\|\|` | OR |
| `!` | NOT |

### 삼항 연산자

```csharp
string result = a == 30 ? "삼십" : "삼십 아님";
// 조건식 ? 참일 때 값 : 거짓일 때 값
```

### null 조건부 연산자

```csharp
// ?. : 객체가 null이면 null 반환, 아니면 멤버 접근
string name = user?.Name;

// ?[] : 컬렉션이 null이면 null 반환
string first = items?[0];

// ?? : 왼쪽이 null이면 오른쪽 값 반환
string username = user?.Name ?? "Guest";
```

중첩 사용 예시:

```csharp
string street = user?.UserAddress?.Street ?? "No Address";
```

### 비트 연산자, 비트 논리 연산자

| 연산자 | 설명 |
|--------|------|
| `<<` | 왼쪽 시프트 |
| `>>` | 오른쪽 시프트 |
| `&` | 논리곱 (AND) |
| `\|` | 논리합 (OR) |
| `^` | 배타적 논리합 (XOR) |
| `~` | 보수 (NOT, 비트 반전) |

## 객체지향 프로그래밍

### 인터페이스의 기본 구현 메서드

레거시 인터페이스에 메서드를 추가할 때, 기존 파생 클래스에 컴파일 에러를 내지 않으려면 **기본 구현**을 제공한다.

```csharp
interface ICharacter
{
    void Move(); // 모든 클래스가 반드시 구현

    void Fly()  // 기본 구현 메서드 — 선택적 오버라이드
    {
        Console.WriteLine("이 캐릭터는 날 수 없습니다.");
    }
}
```

> ⚠️ 기본 구현 메서드는 **인터페이스 참조(업캐스팅)로만 호출 가능**. 클래스 타입 변수로는 접근 불가.

### 추상 클래스

클래스와 인터페이스의 중간. 구현을 가질 수 있지만 **인스턴스화는 불가능**하다.

```csharp
abstract class Animal
{
    public string Name;
    public Animal(string name) { Name = name; }

    public abstract void Sound(); // 파생 클래스에서 반드시 오버라이드

    public void Sleep()           // 기본 구현 제공
    {
        Console.WriteLine($"{Name} 잠들었습니다.");
    }
}
```

| | 인터페이스 | 추상 클래스 |
|--|-----------|------------|
| 필드 | ❌ | ✅ |
| 생성자 | ❌ | ✅ |
| 다중 상속 | ✅ | ❌ |
| 기본 접근 제한자 | `public` | `private` |
| 인스턴스화 | ❌ | ❌ |
