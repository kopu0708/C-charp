# 예외처리 
예외처리.. 우리가 만약 정수형 숫자 만을 입력 받는 프로그램을 짯다고 가정해보자 

그런데 사람 마음이란게 참 알기 힘들지 않는가? 내 마음도 잘 모르겠는게 세상이다. 정수형만 넣으라고 분명 설명 해줬는데 분명 열에 하나는 소수나 문자열을 입력할 것이다. 

이 외에도 갑자기 컴퓨터가 꺼진다거나, 용량 이상의 파일이 한번에 날아와 감당이 안된다거나 이런 사고들이 있다. 

이러한 내가 가정한 상황을 벗어나는 사건들을 예외라 한다. 그리고 이러한 예외가 프로그램의 오류나 다운으로 이어지지 않게 처리하는걸 말 그대로 예외처리라고 하겠다.

그래서 어떻게 하는데요?

### try~catch문 
시도와 잡다? 이게 뭘까 예외를 처리하는 아주 기본이 되는 문법이다. 먼저 어떻게 생겼는지 부터 보자 
```C#
try
{
    // 실행할려는 코드
}
catch(예외_객체_1)
{
    // 예외가 발생했을 때의 처리
}
catch(예외_객체_2)
{
    // 예외가 발생했을 때의 처리
}
```
try 절의 코드 블록에는 예외가 일어나지 않을 경우에 실행되어야 할 코드들이 들어가고, catch 절에는 예외가 발생했을 때의 처리 코드가 들어간다.

말그대로 시도해보고? 예외가 던져지면 잡는다. 이렇게 이해하면 될 듯하다. 그리고 보다시피 하나의 시도에 여러개의 catch문을 놓을 수도 있다.

내 생각인데 if문이나 case랑 비슷한 것 같기도 하다. 분명한 차이점은 if,case 같은 분기문은 조건을 직접 검사하지만, try-catch문은 예외가 터지면 자동적으로 검사한다는 것이다.

참고로 catch는 위에서부터 차례로 검사해서 처음 일치하는 하나만 실행된다. 그래서 더 구체적인 예외를 위에, 포괄적인 예외(Exception)를 아래에 둬야 한다.
